# FavFilter para macOS

Equalizador paramétrico para fones e caixas, com EQ aplicado ao áudio do sistema inteiro.

## O que faz

- **EQ do sistema**: aplica o equalizador a todo o áudio do Mac, de qualquer app.
- **Plugin Audio Unit (AUv3)**: usa o mesmo EQ dentro de DAWs, sem latência extra.
- **Até 15 bandas paramétricas**, com presets e importação de perfis de EQ.
- **Correção por headphone**: aplica uma curva de correção ao seu fone.
- **Analisador em tempo real (RTA)** e **teste ABX cego** para checar se o EQ é audível.
- **Barra de menus**: liga/desliga o EQ do sistema e troca presets sem abrir a janela.
- **Atualizações automáticas**: o app avisa quando há versão nova.

## Requisitos

macOS 15 ou mais recente.

## Instalação

1. Baixe o `.dmg` mais recente em [Releases](../../releases/latest).
2. Abra o `.dmg` e arraste **FavFilter** para **Aplicativos**.
3. Na primeira abertura, o macOS pode bloquear o app por não ser notarizado: clique com o **botão direito** em FavFilter → **Abrir** → **Abrir**.
4. Ao ligar o EQ do sistema, permita **Gravação de Áudio do Sistema** quando o macOS pedir.

As próximas versões chegam sozinhas pelo menu **FavFilter → Check for Updates…**.
